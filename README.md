# Aprende Ortografía y Caligrafía

Una aplicación web interactiva diseñada para ayudar a usuarios de todas las edades a mejorar sus habilidades de ortografía y caligrafía mediante ejercicios prácticos y divertidos.

## 🚀 Características Principales

### ✍️ Módulo de Ortografía
- **Ejercicios de completar palabras**: Practica con palabras con letras faltantes
- **Corrección de errores**: Identifica y corrige palabras mal escritas
- **Dictados virtuales**: Ejercicios de escucha y escritura usando Web Speech API
- **Múltiples niveles de dificultad**: Desde básico hasta avanzado

### 🖋️ Módulo de Caligrafía
- **Práctica de trazado**: Usa el canvas para trazar letras y palabras
- **Retroalimentación visual**: Guías y evaluaciones de tu escritura
- **Progreso por letras**: Domina cada letra del alfabeto gradualmente

### 📊 Sistema de Progreso
- **Registro de usuarios**: Sistema simple de autenticación local
- **Seguimiento de estadísticas**: Puntuación, niveles y precisión
- **Logros y metas**: Sistema de recompensas por progreso
- **Almacenamiento local**: Tus datos se guardan en tu navegador

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica y accesible
- **CSS3**: Grid, Flexbox, Variables CSS, Animaciones
- **JavaScript Vanilla**: ES6+, Modules, Canvas API, Web Storage API
- **Web Speech API**: Para ejercicios de dictado
- **IndexedDB**: Para almacenamiento de datos complejos (opcional)
